# OpenAbyss

You probably want the [original project](https://github.com/cimmerianpit/openabyss).

This is a personal fork with a few buggy, vibed-coded features:

 - macOS build
 - "Immersive" mode, toggled by tab that hides the UI and controls a bit
   more like a modern FPS - WASD, left MB to attack, right MB to use.
 - Console, toggled by §, supporting handful of commands:
   - `god`: God mode
   - `affine on` and `off`: Perspective-correct texture rendering
   - `bright on` and `off`: Full-bright mode
   - `widescreen on` and `off`: Crop the view to 4:3 in immersive or don't.
